## 📌 About This Repository

I build with AI every day, but I wanted to truly understand what's running underneath the hood instead of just prompting. This repository documents my ongoing, public journey to master Data Structures and Algorithms from first principles. Less abstraction, more *"why does this work."*

The core curriculum follows **Abdul Bari's DSA course (C/C++)** combined with rigorous **LeetCode** practice.

## 📂 Repository Structure

Everything is neatly organized by weeks. Inside each folder, you'll find a dedicated `README.md` detailing the concepts covered, along with the corresponding standalone, compilable code files. 

*(Note: Code files contain no comments or extra blank lines—this is an intentional styling choice for clean, minimal code reading, not laziness!)*
